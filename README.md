# Audio Converter Program

A simple and lightweight MP3 to OGG audio converter built with Windows Forms on **.NET 8.0**. 

## Features

* **Drag & Drop:** Drag your MP3 files directly into the window to queue them.
* **Batch Conversion:** Process multiple audio files at once.
* **Lightweight:** Tiny executable file size.

## Requirements

* **Operating System:** Windows 10 / 11
* **Runtime:** [.NET Desktop Runtime 8.0](https://dotnet.microsoft.com/ru-ru/download/dotnet/8.0) must be installed on the user's PC.

## How to Use

1. Launch `Audio Converter Program.exe`.
2. Click **Add MP3** or drag your audio files into the list.
3. Click **Convert**.
4. The converted `.ogg` files will appear in the `Converted` folder next to the program.
